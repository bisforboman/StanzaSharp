So backen Sie einen einfachen Apfelkuchen:

1. Heizen Sie den Backofen auf 180 °C (Umluft 160 °C) vor.
2. Schälen Sie vier mittelgroße Äpfel, entfernen Sie das Kerngehäuse und schneiden Sie sie in dünne Spalten.
3. Verrühren Sie 200 g Mehl, 100 g Zucker, 125 g weiche Butter, 2 Eier und 1 Päckchen Backpulver zu einem glatten Teig.
4. Füllen Sie den Teig in eine gefettete Springform (Ø 26 cm) und verteilen Sie die Äpfel darauf.
5. Backen Sie den Kuchen etwa 45 Minuten lang. Machen Sie die Stäbchenprobe!

Hinweis: Statt Äpfeln können Sie auch Birnen oder Pflaumen verwenden.

Installation der Software

Laden Sie zuerst das Installationsprogramm herunter. Öffnen Sie danach die Datei setup.exe und folgen Sie den Anweisungen auf dem Bildschirm. Starten Sie den Computer neu, wenn Sie dazu aufgefordert werden.

Achtung: Ziehen Sie vor der Reinigung immer den Netzstecker! Verwenden Sie keine scharfen Reinigungsmittel und tauchen Sie das Gerät nicht in Wasser.
