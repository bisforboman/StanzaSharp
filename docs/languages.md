# Supported languages

Generated by `python tools/stanza_resources.py docs` from `src/StanzaSharp/stanza_resources.json` and
`tests/golden/languages/`; don't edit by hand.

StanzaSharp runs 86 of Stanza 1.15.0's languages, each byte for byte against Python Stanza on its golden
text ([verification.md](verification.md)). Select one with `PipelineOptions.Language` (the code) and download its
models with `ModelDownloader.DownloadAsync(dir, options)` or `stanzasharp download --lang CODE`. The processors are
those of the language's `default` package, in Stanza's order.
